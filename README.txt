This is an AI VIRTUAL ASSISTANT for exam/course preparation according to subject
 curriculum.

This project is created using streamlit for ui web interface, 

speech recognition for enabling application to use microphone for speech search/ask/question 
option with default text search/ask/question option.

This project integrates Groq as an LLM for better context understanding and answerin 
according to user intented it to be.

This project uses pypdf for parsing and reading pdf uploaded by user.

And also pyttsx for text to speech conversion library with no limit as it is offline
and has no token limit and uses computer inbuilt voice engine.


TO RUN THIS PROJECT: 

type this in terminal of project folder after cloning this repository:
pip -r install requirements.txt 

to install all necessary libraries for this project

TO RUN THE APP:

type this in terminal : streamlit run virtual_tutor.py

after this default web browser of your system will open and you can check 
project features after entering your own groq api which is free available 

simply search groq and login/ signup and create api and copy it and save some where 
and use it in application
